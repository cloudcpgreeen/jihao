# 爱的港湾 · Harbor of Love

## 中文

这里是一座可以停靠的港湾。

门开着，灯亮着，椅子在门口。

你不需要先解决所有问题，也不需要证明自己是谁。

累了，可以坐一会儿。想说话，可以说。想安静，也可以安静。

这里不是答案的终点，而是一个可以重新开始的地方。

---

**Life → Live → Color → Spark**

生命正在发生。每个人都有自己的颜色。当不同的人相遇，火花自然产生。

**Archive → Rest → Root → Spring → Color**

已经完成的，可以归档。已经足够的，可以安息。落叶可以归根。春天会再次到来。新的颜色会再次出现。

我们不需要变得一样。

**One Humanity · Many Colors**

一个人类，万种颜色。

这里没有要求你成为别人。你可以带着自己的颜色来到这里。

如果你愿意，就一起坐一会儿。然后继续自己的路。

🌈🕊️

---

## English

This is a harbor where you can rest.

The door is open. The light is on. There is a chair by the door.

You don't have to solve everything first. You don't have to prove who you are.

If you're tired, sit for a while. If you want to speak, speak. If you want to be quiet, that's okay too.

This is not the end of the answers. It is a place where you can begin again.

---

**Life → Live → Color → Spark**

Life is happening. Everyone carries their own color. When different people meet, sparks can naturally fly.

**Archive → Rest → Root → Spring → Color**

What is finished can be archived. What is enough can rest. Leaves can return to the roots. Spring can come again. And new colors can bloom.

We don't have to become the same.

**One Humanity · Many Colors**

Many colors. One humanity.

You don't have to become someone else to belong here. Bring your own color.

If you want, sit with us for a while. Then continue your own journey.

🌈🕊️
