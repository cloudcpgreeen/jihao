# 一点协议 (One Point License)

一个开源软件协议。

它和 MIT、Apache、GPL 一样，告诉你：**拿这代码能做什么，不能做什么。**

## 为什么叫「一点」

写这个协议之前，我在做一个用户身份认证的服务（user-svc）。写着写着发现一个问题：所有复杂的权限规则，说到底都在回答同一件事——「什么能做，什么不能做」。而所有「不能做」的背后，其实都指向同一个东西：**不能伤害人。**

那不如反过来想。不要列一百条禁止，只定一条边界。

**爱是唯一的边界。**

这就是「一点」这个名字的来历——把千千万万条规则收敛成一个点。

## 对比传统协议

| 协议 | 核心思路 |
|------|---------|
| MIT | 随便用，不负责 |
| GPL | 随便用，改了要开源 |
| Apache 2.0 | 随便用，专利也授权 |
| **一点** | **随便用，但不许害人** |

MIT 说「我不负责」很容易，但当一段代码真的被拿去作恶的时候呢？一点比 MIT 多了一行底线：**你可以用、可以改、可以卖，不可以压制人。**

## 全文就四句话

**你可以：**
- 自由使用、修改、分发、商用

**你不可以：**
- 用这代码压制人、剥削人、欺骗人
- 宣称这代码是你原创的而否认贡献者
- 用技术替代人与人的真实关系

就这些。不是法律文书，是方向声明。

## 怎么用

1. 把 `LICENSE.md` 复制到你项目根目录
2. 把你自己的名字写在署名那一行
3. 完成

不需要律师审核，不需要法务流程。适合个人项目、小团队、开源爱好者的日常使用。

## 关于这个仓库

`user-svc` 是一个用户身份认证服务的 Rust 实现。它是我自己学习和实践 Rust 的项目，也是「一点」协议的**第一个使用者**——协议自己遵守自己。

## 为什么写这个协议

因为我身边的家人和朋友担心我。他们看到我在写代码、在谈「光」和「记号」、在半夜推仓库，觉得不对劲。

这些担心是合理的——一个人如果把自己关起来写别人看不懂的东西，确实让人不放心。

但这事其实很简单：

- 我是一个基督徒程序员
- 我在用自己的技能做开源项目
- 「爱是唯一的边界」是我的信仰在代码里的自然表达
- 和世界上成千上万用信仰指导工作的程序员没有区别

这个协议不是玄学。它是一个开源许可证。你打开任何一个 GitHub 仓库，里面都有 `LICENSE` 文件。这个是我的。
