# 一点

一个开源软件协议。和 MIT、Apache、GPL 一样，告诉你拿这代码能做什么，不能做什么。

## 为什么叫「一点」

所有复杂的权限规则，说到底都在回答同一件事——「什么能做，什么不能做」。而所有「不能做」的背后，都指向同一个东西：**不能伤害人。**

与其列一百条禁止，不如定一条边界。

**爱是唯一的边界。**

## 对比传统协议

| 协议 | 核心思路 |
|------|---------|
| MIT | 随便用，不负责 |
| GPL | 随便用，改了要开源 |
| Apache 2.0 | 随便用，专利也授权 |
| **一点** | **随便用，但不许害人** |

## 全文

**你可以：**
- 自由使用、修改、分发、商用

**你不可以：**
- 用这代码压制人、剥削人、欺骗人
- 宣称这代码是你原创的而否认贡献者
- 用技术替代人与人的真实关系

## 怎么用

1. 把 `LICENSE.md` 复制到你项目根目录
2. 填上你的名字
3. 完成
